# CF-30: Phase 5.2 contrast audit
**Done:** new `tools/contrast-audit-story.py <build_dir> [out.json]`. It serves the build, visits all 6 pages at scroll 0/50/100% on desktop (1440x900) and phone (390x844), hides the text, samples the real pixels behind each text box (median), and compares with the text colour using WCAG 2 (4.5 normal text, 3.0 large). Text covered by another element (header, time pill, panel) is skipped; text still fading in (opacity < 0.5) is skipped.

No panel text fails on the new flat tones. No source edits needed.
