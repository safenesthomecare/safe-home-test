# Pending assets

None. All foreground props and icons the story uses are drawn in the SafeNest Story UI Kit and in `frontend/src/components/story/ArtifactIcon.jsx` (35 icons).

Left on other icon sets on purpose: the white check inside the filled circles on the Services list, and the filled rating stars (lucide). `ArtifactIcon` also has `check` and `star` outline versions if you want to switch.

An unknown icon name renders a dashed circle and gets `data-missing="<name>"`, so gaps are easy to find.
