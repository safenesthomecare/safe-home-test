# Figure style (Phase 0)
- Source: `figure.jsx`; `Person` in `art.jsx` now points to it, so every world already uses it.
- Props: x, y, s, face, skin, hair, top, bottom, shoe, pose, walk, outfit, hairStyle, glasses, cane, elder, item, lean.
- Poses: stand, walk, wave, open, hold, give, point, sit. Add a pose by adding one line (arm and leg angles) to POSES.
- Outfits: tee, scrubs, cardigan. Hair: short, bun, curly, wavy, long, bald.
- Look: one shared soft-shade gradient per figure, thin ink line, no blur filters.
- Origin is the feet; sitting figures keep feet on the floor.
